# Roadmap

This is a direction for future work, not a list of implemented features.

1. Improve reliability: stable window lifecycle tracking, event-driven Accessibility observers, minimum-size constraints, application compatibility tests, and multi-monitor/Space regression scenarios.
2. Bring interactions closer to COSMIC: directional movement that restructures groups, drag target zones and placement preview, plus resize feedback.
3. Add layout groups: selection of ancestor groups and stack/tab presentation adapted to macOS APIs.
4. Product polish: configurable shortcuts, app rules, saved layouts, additional localization, and Developer ID signed/notarized distribution.

COSMIC is a compositor with capabilities a macOS Accessibility client does not share. Features should be designed and verified for macOS rather than claiming exact parity.
